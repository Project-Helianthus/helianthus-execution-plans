# Multi-runtime semantic platform history

This directory preserves the pre-simplification planning corpus as historical context.
It is archived and non-executable. Its token, hash, attestation, routing, dispatch,
authorization, ready-set, release-proof, and unlock language has no current authority.

Agents must use `multi-runtime-semantic-platform.locked/` for dependency guidance and
must determine actual readiness from current GitHub state and the owning implementation
repositories.
