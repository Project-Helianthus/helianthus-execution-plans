# 0.8 issue map

This future guide retains the stable `INT-18`, `INT-22`, `INT-23` and `INT-24`
outcomes from the former combined guide. It creates no issues and makes no claim
that a repository or issue is ready. Select repository-local issues only after the
0.7 prerequisite is accepted and the native driver ownership split is approved.

The public [0.8 software project](https://github.com/orgs/Project-Helianthus/projects/4)
is a planning tracker. It is not a release authorization, build input or proof of
implementation.
