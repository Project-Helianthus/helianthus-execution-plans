Each row is one future executable issue owned by exactly one repository. The existing
`.github` governance issue creates the two public Modbus repositories; their destination
bootstrap rows depend on it and run only after each repository exists. Private repository
governance creation remains deferred to M0-04, followed by destination bootstraps M0-05
and M0-07, all under future explicit authorization. This map contains 46 issues.
Milestones are groupings only.

are not progress.

disposition releases M4, and completed Growatt `NO_ADMISSIBLE_PROFILE` releases Huawei
while preserving the pre-published public evidence/unsupported disposition and creating no
code, catalog entry, support claim, or later companion docs change.

contract set; it is not replaced or rewritten. PR #89 adds M1-05 as a corrective M1
companion after M1-04, then M1-06 code, then the M2-01 full producer-SHA pin; issue #88 is
tracking metadata only. There is no
